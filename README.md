# e-Ticket: Taylor Swift – The Eras Tour

This is a simple interactive ticket purchase page built as part of an Alura course.

It includes:

- A form to select ticket type and quantity
- JavaScript logic to handle inventory and alerts
- HTML and CSS for layout and styling

All interactions are simulated for educational purposes only.
